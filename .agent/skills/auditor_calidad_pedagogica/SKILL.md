# Auditor de Calidad Pedagógica e Institucional

Este skill ejecuta un proceso de revisión exhaustiva de 5 niveles para asegurar que ninguna planeación o secuencia contenga inconsistencias teóricas, ambigüedades de evaluación o faltas de rigor curricular.

## 🔍 Niveles de Auditoría

1. **Auditoría Curricular:** Verificación de correspondencia exacta entre Estándar, DBA y Grado.
2. **Auditoría de Tiempos:** Confirmación de que las actividades descritas sean ejecutables en el número de sesiones solicitadas (60 min/sesión).
3. **Auditoría Evaluativa:** Coherencia entre objetivos planteados, actividades realizadas y criterios de la rúbrica analítica.
4. **Auditoría de Inclusión:** Verificación de alternativas DUA/PIAR diferenciadas.
5. **Auditoría de Estilo y Formato:** Saneamiento de textos, formato tipográfico y corrección gramatical.
